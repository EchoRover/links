# linkCS

A quick-links hub for **IIT Delhi Abu Dhabi — B.Tech CSE Year 3** students. Every course resource, portal, and update worth clicking, on one page.

> **Live site:** [linkcs.vercel.app](https://linkcs.vercel.app)
> **Sister site:** [linkeen.vercel.app](https://linkeen.vercel.app) (BTech Energy Engineering)

---

## What's on the page

| Page | What it does |
|---|---|
| **Home** `/` | Quick-link pills, the live **class card** (what's on now / next, room, countdown), course cards, and **Updates** (assignments + quizzes, expired items auto-hide) |
| **Bus** `/bus` | Shuttle times both ways, picked by the device's day (Mon-Thu, Friday, weekend sheets; night runs past midnight count as the previous day) |
| **Mess** `/mess` | This week's menu off the mess sheet, with a one-tap "this dish was wrong" report |
| **Rooms** `/rooms` | Live occupancy for every classroom and lab from all 11 programs' timetables, with a Mon-Fri switcher and floor plans |
| **Week** `/week` | Year 3 CSE timetable as a week or day grid, G1/G2 filter |
| **Timetables** `/timetables` | Every program's timetable sheet |
| **3D** `/3d`, `/campus`, `/m3`, `/m4` | M3 + M4 and the campus in 3D, rooms lit by live occupancy |
| **Predict** `/predict` | Question Prediction Machine: classmates guess which tut-sheet problems the ACOL351 quiz asks |
| **Archive** `/archive/` | The Year 2 directory, frozen, with its own CSS |

Holidays and **make-up days** (a working day that runs another weekday's
timetable) come from `data/institute/calendar.json`. Every page picks a
date's classes through `classDay(date)`, never `getDay()`.

## Visual elements

- **Three-layer circuit board** (SVG) — deepest layer in indigo (heavily blurred), middle in cyan (lightly blurred), top in main blue (sharp). Light pulses zip slowly along each layer's traces via `stroke-dasharray` animation.
- **Interactive dot particles** (canvas) — 18 dots tethered to the top-layer paths. They walk along the traces, get gently pulled toward the cursor, and snap back. Pull too hard and the rope breaks — they drift freely then re-attach to the nearest path.
- **Translucent cover** dims the circuit/dots behind the content. Removed in hide-mode.

│   ├── building.js       # 3D viewer for m3 / m4 / both;  campus.js for the campus
│   └── hit.js            # usage counter (see Analytics)
├── api/                  # Vercel functions on Upstash Redis
│   ├── hit.js            # usage counts
│   ├── report.js         # mess "this was wrong" reports

│   ├── mess/             # SOURCE: menu, service rotation, saved menus
│   └── *-data.js         # generated room / building / campus models

Static site, no bundler. The JSON under `data/` is the source of truth;
`python3 tools/build_data.py` compiles it into `js/gen/data.js`.

### Checks

`python3 tools/check.py` runs every check: data, mess, internal links
(honours `vercel.json`), timetable vs the published PDF, and routing. Run it
before pushing; `main` deploys straight to the live site.

### Analytics

`js/hit.js` sends one count per page view and per link tap to `api/hit.js`.
Counts only: no cookies, IPs or names; distinct devices are counted with a
Redis HyperLogLog off a random per-browser id; keys expire after 400 days.

- `python3 tools/stats.py [days]` prints views, devices, hours, phone vs desktop and top links.
- Open any page once with `?notrack=1` to stop counting your own browser (`?notrack=0` undoes it).

## Editing data

### Courses, timetable, holidays

Edit the JSON, then rebuild and check:

- course titles, credits, LTP, links: `data/linkcs/courses.json`
- class blocks: `data/linkcs/timetable.json`
- term dates, holidays (`noClass`), make-up days (`makeup`, e.g. `"2026-11-30": "Thursday"`): `data/institute/calendar.json`

```
python3 tools/build_data.py && python3 tools/check.py
```

### Add an assignment or quiz

Call `addUpdate(...)` anywhere in `js/scripts.js` before `DOMContentLoaded`:

```js
addUpdate("assignments", "ACOL333: Lab 1, 14/09/2026", "2026-9-14");
addUpdate("quizzes",     "ACOL351: Quiz 1, 20/09/2026", "2026-9-20");
```

- Arg 1: `"assignments"` or `"quizzes"`
- Arg 2: `"CODE: event text, DD/MM/YYYY"` — the colon and last comma are parsed to extract the code and date label
- Arg 3: `"YYYY-M-D"` expiry — the item disappears after this date

### Change a quick-link pill

The quick-link pills are hardcoded in `index.html` under the `.hero-quick` and `.quick-secondary` sections. Edit the `<a>` tags directly.

## Theming

The color system uses CSS custom properties under `:root[data-theme="light"]` and `:root[data-theme="dark"]` in `css/styles.css`. Main tokens: `--coral` (primary blue), `--cyan`, `--indigo`, `--deep`, `--red`, plus `--bg`, `--fg`, `--rule` families.

Theme is set on first paint from `localStorage` + `prefers-color-scheme`, then toggled with the `◐` button (persists to `localStorage`).
