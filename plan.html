Where this comes from. The public ZU Abu Dhabi campus PDF is an AutoCAD export, not a picture. It still carries 795 named CAD layers and 414,355 line segments, so walls, doors, columns and glazing come out separated and exact. Extractor: tools/extract_floorplan.py. What it does not cover. That drawing is the ground floor only (…REV9_G.F), so M3 level 1, M4 level 1 and M2 level 2 are not here yet. The CAD carries no room numbers either, so which polygon is which code is set by hand in label mode.
