Every cohort

All eleven running programmes, Semester 1 2026–27, read out of the academic office’s own workbooks. Not linked from anywhere — the sheets carry real errors and this page shows them as they are.

Where this comes from. The five schedule workbooks, read cell by cell — group membership from the merged cell spans, and the two Year 2 blocks that exist only as a picture pasted over the grid. Hidden worksheets are skipped, because a hidden sheet is a programme that is not running.

What has been corrected. Where a cell printed a room code that contradicts the room name beside it, the code was corrected — the academic office’s own rule, applied to 13 cells. Two blocks print an end time before their start and are read as 50-minute tutorials. Every one of those is listed in the header of data/rooms-data.js.

Use the week grid instead if you are Y3 CSE. It is the only cohort mechanically reconciled against its published PDF, and it draws time to scale. This page orders blocks but does not size them.
